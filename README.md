# Enterprise Security & Dynamic Inventory Engine 🚀

A highly professional, multi-modular backend console engine written in **Advanced C++**. This system integrates custom cryptography paradigms alongside low-level memory architectures to implement secure data handling.

## 🛠️ Advanced Architectural Components

### 1. Custom Security Subsystem (Cryptography)
* **Cryptographic Hashing:** Implements a non-reversible customized polynomial string hashing algorithm (`DJB2` variant). Passwords are never stored in plain text; instead, validation occurs via bitwise-shifted binary hash evaluations.
* **Serialized Identity Blocks:** Employs precise block-writing constraints (`ios::binary`) to log persistent binary credential signatures safely.

### 2. Dynamic Memory Infrastructure (Advanced DSA)
* **Dynamic Linked Structures:** The asset inventory relies completely on a heap-allocated **Singly Linked List** pipeline rather than simple static arrays, allowing dynamic runtime resizing.
* **Custom File Serialization:** Automatically parses comma-delimited data structures dynamically to sync active heap memory configurations with permanent static storage.

## 📈 Technical Metrics & Concepts Demonstrated
* **Languages:** C++ (Standard ISO Engine)
* **Data Structures:** Singly Linked Lists, Custom Hash Key Generations.
* **File I/O Streams:** Tokenization via Stream-Buffering (`ifstream` / `ofstream`), structural binary flags.
* **Object-Oriented Integrity:** Full utilization of Encapsulation, Pointer Dereferencing, Class Destructor memory sweeps (preventing leaks).
